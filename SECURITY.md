# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email **ceo@carterwarrens.com** with:

- the affected repository and version or commit;
- a concise description of the issue and potential impact;
- reproducible steps or a proof of concept, when safe to provide; and
- any suggested mitigation.

Please allow reasonable time for validation and remediation before public disclosure. Carter Warrens will acknowledge credible reports and coordinate next steps based on severity and affected systems.

Research prototypes and reference implementations must not be treated as production-safe unless their repository explicitly states otherwise.
